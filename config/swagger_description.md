REST API школы: учителя и ученики входят по логину и паролю, получают JWT и передают его
с каждым запросом.

### Как попробовать
1. **Authorize → basicAuth**: логин и пароль (демо-пользователи: `teacher`, `student1`, `student2`)
   → Authorize → Close.
2. **POST /api/auth/login/** → Try it out → Execute. Swagger сам закодирует `username:password`
   в Base64 и отправит `Authorization: Basic …`.
3. Access-токен из ответа автоматически подставится в **jwtAuth**, и остальные запросы уже
   авторизованы. Если этого не произошло, скопируйте `access` в Authorize → jwtAuth (без `Bearer`).
4. Access-токен живёт 15 минут: обновите его через **POST /api/auth/refresh/** (новый токен
   подставится сам) или повторите шаг 2.

### Роли
- **Учитель** видит все оценки, выставляет и меняет свои, видит список учеников.
- **Ученик** видит только свои оценки, без права изменения.

Регистрация (`POST /api/auth/register/`) создаёт ученика.
Ошибки: `401` — нет или неверные учётные данные/токен, `403` — роли не хватает прав,
`429` — слишком много попыток входа.
